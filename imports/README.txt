IMPORTS — order codes for a Commissioner Mode league

Put each cycle's codes here, then press [O] on the Commissioner Desk.

  * A Google Form's responses: in the Form, Responses → (the three dots) → Download responses (.csv).
    Drop the CSV here as it is. The column holding the codes is found automatically, and the
    Timestamp column decides which code is newest when a team submits more than once.
  * Or a plain .txt file with one code per line.

Nothing is applied until you've read the import report and confirmed. A snapshot is saved before
and after every import ([U] on the desk rolls back).
