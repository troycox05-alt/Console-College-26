UNIVERSES — which programs, coaches and names a world uses

Put universe files (*.json) in this folder. Settings -> [U] lists them and picks the one new
worlds use; every save remembers its own. [X] on that screen exports the universe in use as a
complete, editable template. Manual chapter 33 has the details.

Saves made before v29 load with real_2026.json if it's here.
